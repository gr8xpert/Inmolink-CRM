## [Unreleased]

### Changed
- Test hygiene (S2-F3): `test:int:root` runs every root project and fails at the end (`scripts/ci/run-projects.ts`); the outbox idle-pickup test uses the dispatcher's new `onClaim` observer instead of wall-clock latency; a migration backfill test for 0033; `[S1-10]` tags on the bundle budget output; `toCommission` throws an `AppError`. No new dependencies. [S2-F3]
- Settings and impersonation hardening (S2-F2): the shared settings read drops the Client Mode PIN policy (new internal `getClientModePolicy`); staff impersonating a member are rate-limited in their own bucket; logs redact agency contact, address, document and DTO name fields. No new dependencies. [S2-F2]
- Identity query and index follow-ups (S2-F1): an impersonated request runs 3 statements before its handler (one `app_auth` staff-login read, one member + session read, the tenant); keyset ordering uses the indexable `date_trunc('milliseconds', col, 'UTC')` with expression indexes for the staff tenants and staff access lists (migration 0039); audit log months older than 24 months move to schema `audit_archive`, kept append-only (migration 0040, runbook `audit-archive.md`). No new dependencies. [S2-F1]

### Fixed
- Taxonomy resolver at scale (S2-F5, sprint S2 review): stored `name_key` columns with btree + GIN trigram indexes (`fastupdate = off`), one GIN probe per key in a LATERAL, explicit `pg_trgm.similarity_threshold`, `locations_level_idx` for level hints (migration 0044). Exact lookups 500 keys in ~6 ms (was 17.5 s), fuzzy 2–5 ms per key (was ~1.3 s). No new dependencies. [S2-F5]
- Taxonomy (S2-F4, sprint S2 review): `ß` folded to `ss` in both alias and name keys (migration 0043); the unmatched queue no longer reopens mapped values whose alias exists, writes in sorted chunks of 1,000, and skips values over 200 characters; location create validates its polygon; translation sets refuse a repeated locale; turbo caches the copied MapLibre worker so the S2-04 e2e passes on build cache hits. No new dependencies. [S2-F4]
- Legacy taxonomy import (S2-06 recheck): location ancestor lookup chunked (bind-parameter limit on large legacy levels); staff-set manual maps win over the resolver and are reported as `manual`. [S2-06]
