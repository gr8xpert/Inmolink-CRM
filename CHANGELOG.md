# Changelog

All notable changes to this project are documented here. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added
- Monorepo scaffold: pnpm workspace + Turborepo with every app and package from PLAN §5.7 as a building skeleton, strict TypeScript/Biome/Vitest presets in `@inmolink/config`, husky + lint-staged, `pnpm verify` (Turbo `--affected`), stubbed root scripts for later tasks, and ADR 0001 with pinned versions. New dev dependencies: turbo, @biomejs/biome, typescript, vitest, tsdown, tsx, husky, lint-staged, @types/node; next, react, react-dom in the Next.js apps. [S0-01]
- Local stack: `docker-compose.yml` with `dev` and `test` profiles (PostgreSQL 18 + PostGIS/pgvector/pg_trgm/pg_partman, PgBouncer, two Redis instances, Meilisearch, MinIO, Mailpit, OTel collector + Jaeger), `scripts/ops/health.ts` (`pnpm infra:health[:test]`), `.env.test.example`. `pnpm dev` starts infra first. New root dev dependencies: pg, @types/pg, ioredis. [S0-02]
- Platform core: `@inmolink/platform` subpaths `config`, `logger`, `errors`, `ids`, `clock`, `crypto`, `crypto/password`, `http`; `AppError` + `ErrorCodes` in `@inmolink/contracts`; ADR 0003 (Argon2id params, AES-256-GCM envelope, rotation, HMAC). `.env.example` gains local-only `ENCRYPTION_KEYS`, `ENCRYPTION_ACTIVE_KEY_ID`, `HMAC_KEY`. New dependencies: zod (contracts, platform), pino, @node-rs/argon2. [S0-03]
- Database package: `@inmolink/db` per-role pools (`app_user`, `app_system`, `app_public`) with `withTenant`, `withSystem`, `withPublicRead`, `getPgClient`, `configureDb`/`closeDb`; `pnpm db:migrate` (advisory-locked role bootstrap with SCRAM verifiers and role-level statement timeouts, then drizzle-kit migrations as `app_owner`), `pnpm db:migrate:test`, `pnpm db:generate`. `DATABASE_URL_APP_SYSTEM` becomes optional and is refused for HTTP processes in production. New dependencies: drizzle-orm, pg (db); drizzle-kit, @types/pg, tsx (db, dev). [S0-04]
- Tenant registry and RLS: `packages/db/src/tenancy/registry.ts` (STRICT / NETWORK_READ / PUBLIC_READ tenant tables + explicit global tables), `pnpm db:rls[:test]` generates `packages/db/rls/policies.sql` (helpers, forced RLS, policies, per-table grants), applies it and runs the guard; `pnpm test:isolation` (in `verify`) runs the cross-tenant suite generated from the registry plus guard tests. App roles no longer get default table/function privileges: grants come only from `db:rls`. Root dev dependencies: @inmolink/db, @inmolink/platform, drizzle-orm. [S0-05]
- Outbox and queues: `outbox_events` (STRICT, append-only tenant table via the new registry flag `appendOnly`; nil-UUID agency for platform events) with `@inmolink/platform/outbox` (`defineEvent`, `emit` + NOTIFY in the caller's transaction, `subscribe`, lease-based dispatcher with SKIP LOCKED claims, batch 500, LISTEN wake-up + polling fallback, retries/dead-lettering, retention prune, replay) and `@inmolink/db` `listen()` over the new optional `DATABASE_URL_LISTEN` (direct connection, refused for HTTP processes in production); `@inmolink/platform/queue` (`defineJob`, `registerPool`, stable job IDs, retries/backoff, `<pool>.dead` dead-letter queues, debounce via BullMQ deduplication, per-group fair share by backlog-depth priority + Lua lease caps, same-tick enqueues batched into `addBulk`); `pnpm ops:replay-outbox`; `pnpm test:perf:root` (in `verify`, runs last). New dependencies: bullmq, ioredis, drizzle-orm (platform); zod (root, dev). [S0-06]
- Cache, rate limits, feature flags: `@inmolink/platform/cache` (read-through on redis-cache with per-process single-flight, tag invalidation by random tag versions, optional 60 s in-process LRU, `cacheKey()` builder whose branded keys always name their tenant scope, degrade-to-loader when Redis is down), `@inmolink/platform/rate-limit` (sliding-window counter in one Lua script, scopes ip/user/key/tenant, HMAC'd identities, credential rules must fail closed, Fastify plugin with 429 + `Retry-After`, IPv6 /64 buckets), `@inmolink/platform/flags` (`feature_flags` global table, `flag(ctx, key)` with per-agency overrides, cached 60 s); logger drops ioredis `command`/`args` from errors. New dependency: fastify (platform dev + optional peer, root dev). [S0-07]
